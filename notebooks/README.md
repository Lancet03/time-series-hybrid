# Анализ экспериментов

`analysis_results.ipynb` читает сохранённые результаты `time-series-hybrid`.
Веса моделей и GPU для анализа не нужны. В ноутбуке есть общие метрики,
сравнение гибрида с baseline, ошибки по шагам и каналам, интервалы, время,
выбор ARIMA и просмотр отдельных окон с компонентами гибрида.

## Открытие

Из корня проекта, PowerShell:

```powershell
.\.venv\Scripts\python.exe -m jupyterlab notebooks/analysis_results.ipynb
```

Выберите ядро **Python (time-series-hybrid)** и выполните **Run All**.
В VS Code можно открыть файл напрямую и выбрать интерпретатор
`.venv\Scripts\python.exe`.

Зависимости Jupyter уже установлены в текущем `.venv`. Для нового окружения:

```powershell
uv --cache-dir .cache/uv-notebooks pip install --python .venv/Scripts/python.exe -e ".[notebooks]"
.\.venv\Scripts\python.exe -m ipykernel install --prefix .venv --name time-series-hybrid --display-name "Python (time-series-hybrid)"
```

## Настройки

В первой ячейке кода:

- `RUN_ID = None` выбирает последний завершённый полный исходный запуск.
  Smoke-тесты и объединённые отчёты пропускаются. Для фиксированного эксперимента
  задайте, например, `RUN_ID = "20261031T092812Z-f63e1045"`.
- `DATASET` и `SEED` выбирают датасет и seed.
- `HORIZON`, `CHANNEL`, `ORIGIN` выбирают пример прогноза; `None` использует
  наибольший горизонт, первый канал и первое test-окно соответственно.
- `COMPUTE_DETAILS = False` пропускает потоковый расчёт по каналам и окнам.

После изменения этих настроек выполните **Run All**. В конце ноутбука также
есть форма выбора горизонта, канала и origin с кнопкой «Построить».
Для неё достаточно уже выполненных предыдущих ячеек.

## Выходные файлы

Рисунки PNG и таблицы CSV сохраняются в
`outputs/<run-id>/analysis/notebook/`. Исходные результаты не изменяются.
Большие Parquet читаются порциями; для одного окна используется фильтрация.
Веса моделей не загружаются и прогнозирование не повторяется.

Общие MSE/MAE используют нормализацию по train, а графики отдельных прогнозов —
исходные единицы. Перекрывающиеся test-окна зависимы: доля выигранных окон не
является тестом статистической значимости. NPY хранит индексы каналов без имён
датчиков; ноутбук сохраняет эти обозначения.
