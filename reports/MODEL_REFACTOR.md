# Проверка структуры моделей — 28 октября 2026

Реализации AR, ARIMA, DLinear, TSMixer, ModernTCN, PatchTST, iTransformer,
Chronos, TimesFM, Moirai разнесены по отдельным файлам. Гибриды сохранены.
LastValue, SeasonalNaive, ETS и отдельный Linear удалены из рабочего каталога моделей,
реестра и актуальных конфигов. Исторические отчёты сохранены.

Пять сетей и необходимые общие слои перенесены из соседнего HN-MVTS.
Сравнение AST подтвердило совпадение всех скопированных определений классов,
включая Hyper. Численные тесты Base подтвердили одинаковую инициализацию,
forward и градиенты. Runner обучает Base через адаптеры в файлах моделей.

Проверки: 33 теста pytest, Ruff, короткие реальные запуски всех десяти моделей
и ARIMA + Chronos. В обоих окружениях failures.json пуст, статус completed.
Проверки выполнены на CPU; GPU в этой серии не проверялся.
