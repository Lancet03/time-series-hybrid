# Пять авторских сетей HN-MVTS на ноутбуке

Дата: **28 октября 2026**. Запуск: `20261028T112551Z-dd934c45`.
Все пять задач завершены, `failures.json` содержит `[]`.

[HTML-отчёт](report.html) · [Все метрики](metrics.csv) · [Конфиг](resolved.yaml) ·
[Окружение и модели](manifest.json) · [Оборудование и время](laptop.json) ·

Использованы Base-классы DLinear, TSMixer, ModernTCN, PatchTST и InverseTransformer
из локального HN-MVTS, commit `e86c58a315576cef021d99e04b9b5fef55ddd6d6`.
В коде сетей изменены только импорты `layers` на относительные.
Размеры сетей, конструкторы, forward и RevIN сохранены.

Оборудование: Intel Core Ultra 9 285H, 31.4 ГиБ RAM, Intel Arc 140T.
В этом запуске использован **CPU**, 4 потока, PyTorch 2.14.1+cpu, Python 3.12.15.
Работа на GPU не проверялась. FM-пакеты и checkpoints для этого запуска не нужны.

Параметры пилота: ETTm1, первые 57 600 точек, все 7 каналов, split 6:2:2,
L=336, H=48, seed=0. Для каждой сети: 2 эпохи, 512 равномерно выбранных
train-окон, batch=16, по 16 validation/test origins. Лучший checkpoint выбран
по validation; test не участвует в выборе эпохи. Протокол метрик — `common`.

| Сеть | Время fit, с | Пиковый RSS процесса, МиБ |
|---|---:|---:|
| DLinear | 3.65 | 333 |
| TSMixer | 0.92 | 342 |
| ModernTCN | 12.03 | 424 |
| PatchTST | 7.03 | 412 |
| iTransformer | 1.73 | 406 |

Полное время команды, включая импорт, подготовку и отчёт: **30.77 с**.
Время fit включает validation на каждой эпохе. RSS относится ко всему процессу,
включая уже загруженные библиотеки; он не измеряет память отдельной сети.
Это один запуск при текущей загрузке ноутбука, не изолированный benchmark скорости.

Этот прогон подтверждает работоспособность переноса. Двух эпох, сокращённых
train-окон и 16 test origins недостаточно для выводов о качестве моделей или
совпадении с публикациями. Полная конфигурация `configs/hn_models.yaml`
не ограничивает окна и оценивает H=48/96, но полная сетка здесь не выполнена.

Повторить из каталога `time-series-hybrid`:

```powershell
.\.venv\Scripts\python.exe -m tshybrid run configs/hn_models_laptop.yaml
```
